


====== 关于订单出单 ======

  [下单时]
  收银系统的本地打印最优先(如果本地打印了，云服务打印机不打印)
  对于无需在线支付的订单(非在线支付的订单或在线支付金额为0), 下单的时候收银端打印机出单
  堂点比较特殊{
    快餐(特殊的堂点)不出单
    开启了预付款模式的扫码堂点 不出单
    对于传统打印， 询问客户要不要打单。
    其他的，客户配置了出单, 才出单
  }




  [确认时]
  1、对于外卖和堂点订单, 确认的时候厨房打印机出单
  2、标签打印机出单

  [加菜、退菜]
  收银端打印机和厨房打印机都出单

  [催单、在线支付完成]
  收银系统的本地打印最优先(如果本地打印了，云服务打印机不打印)
  收银端打印机出单（之前下单的时候没出单， 支付完成后才出单 -- 避免顾客以为又下一个新单）
  堂点比较特殊, 支付完成都出单


  [订单小票补打]
  客户选择的打印机出单，或当前有线打印机出单


====== 关于自动确认订单 ======

下单时候自动确认:
  来自店内设备下单
     堂点、外卖、预订 自动确认

  来自店外设备下单
      非在线支付的外卖订单
      堂点订单


支付完成时候的自动确认:
  来自店内设备下单
    外卖、预订 自动确认

  来自店外设备下单
    在线支付完成时候自动确认:
      在线支付的外卖订单
      在线支付的预订订单(系统默认自动确认, 跟是否开启自动确认无关)




====== 桌台变更出单 ======

  [换台、并台]
  收银端打印机出单





====== 排号出单 ======

  [入队]
  排号打印机出单

  [排号小票补打]
  客户选择的排号打印机，或当前有线打印机出单
